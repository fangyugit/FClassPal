明暗模式

黑暗模式对十套风格都生效：液态玻璃 / MD3 / Fluent 走 Monet 暗色 方案（主色自动换成暗底可读的色调），固定配色主题只压暗表面、保留各自的强调色。

十套风格彼此独立：每套都有自己的形状、表面、按钮与动效语言， 不是同一套壳换色。液态玻璃 / MD3 / Fluent 三套跟随壁纸取色； MIUIX 与鸿蒙使用官方规范固定配色， Kitty / 玉桂狗 / 库洛米 / 美乐蒂 / 三丽鸥是角色扮演配色，均不跟壁纸走。
